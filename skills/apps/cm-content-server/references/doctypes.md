# Content-Server doctype definitions
This specification is focused on the creation of document-types, also called content-types. Both are describing 
the concept of creating a new object definition for the content-server.

## Example doctype definition
- read within the workspace the definition apps/content-server/modules/server/doctypes/src/main/resources/framework/doctypes/blueprint/blueprint-doctypes.xml
- The XML file contains the blueprint definitions for the content-server doctypes.

## Important information
- never modify the blueprint definitions, as they are used for the initial setup of the content-server.
- Always use a xml definition located in an extension.
