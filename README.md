# CoreMedia agent skills

## Overview
The CoreMedia agent skills are organized into three main categories: 
- Workspace tooling,  
- API tooling, 
- And application-specific skills. 

Each skill is designed to assist with specific tasks related to CoreMedia's content management and delivery systems.

## Installation 
The agent plugins are standalone and installed via the command line.
See [INSTALL.md](INSTALL.md) for Claude Code, GitHub Copilot, and OpenAI Codex instructions.
